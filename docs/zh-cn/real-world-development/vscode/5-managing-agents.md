代理模式会自主探索代码库、提出更改、编辑文件并运行命令。VS Code 中的 Copilot Chat 会实时显示工具调用和文件编辑，可在编辑器中检查差异、接受或撤销单项更改，并通过后续提示引导工作。

本练习将实时监控无障碍智能体、审查并接受文件编辑，并在同一会话中要求它添加浅色模式。

在本练习中，你将：

- 实时监控无障碍智能体的工作。
- 审查并接受建议的文件编辑。
- 在会话进行中引导智能体，要求它同时添加浅色模式开关。

## 场景

[练习 4][previous-lesson]中的无障碍智能体正在实现高对比度模式。设计团队又提出浅色模式需求。继续引导现有会话，而不是从头开始，以便复用已有上下文。

## 监控 Copilot 进度

Copilot Chat 会显示智能体探索的文件、运行的命令和提出的编辑。每项编辑都会内联显示差异和 **Keep**/**Undo** 控件。

1. 返回练习 4 的 Copilot Chat 视图。
2. 智能体工作时滚动聊天记录，查看它执行的每次工具调用，包括文件读取、编辑和请求运行的终端命令。
3. 智能体提出文件编辑时，差异会内联显示：
   - 选择 **Keep** 接受更改。
   - 选择 **Undo** 撤销更改，让智能体重新尝试。
4. 选择 Chat 顶部的 **Files changed**，查看本次会话中智能体修改的完整文件集。

> [!NOTE]
> 如果工具调用需要权限（例如运行终端命令），智能体会暂停并显示 **Allow** 提示。只批准你认可的命令。

5. 等待智能体完成高对比度模式，并阅读它对更改的总结。

## 引导智能体添加浅色模式

在同一会话中追加浅色模式，智能体便可保留已有组件、样式和 local storage 实现上下文。

1. 在 Copilot Chat 输入以下后续提示：

   ```plaintext
   做得不错！现在在高对比度开关旁添加浅色模式开关。浅色模式应采用相同模式，通过 local storage 持久化，并可从 UI 的同一区域访问。用户应能独立启用高对比度和浅色模式。
   ```

2. 查看智能体提出的每项编辑，并使用 **Keep** 或 **Undo** 审查。
3. 如果方向不合适，选择输入框旁的 **Stop**，再发送澄清提示。

智能体会继续处理已有工作，探索之前创建的更改，并为浅色模式提出额外更改。

> [!TIP]
> 通过后续提示引导正在进行的会话通常比重新开始更快。可要求简化 CSS、调整开关布局或扩展键盘快捷键等功能。

## 审查更改并提交

提交前检查智能体修改的所有内容。

1. 在 VS Code 中打开 **Source Control** 视图。
2. 检查更改文件列表，确认 Astro 组件、样式和相关测试的更新。
3. 查看差异，确认实现包含 ARIA 属性、键盘导航、语义 HTML 和 local storage 持久化。
4. 满意后，在 Source Control 面板中暂存并提交更改。下一课会发布这些更改。

## 总结和后续步骤

本练习使用 Copilot Chat 代理模式监控并引导正在进行的会话：逐项审查文件编辑、接受或拒绝更改，并发送后续提示扩展任务，同时保留已有上下文。

在本练习中，你了解了：

- 实时监控智能体工作。
- 接受或拒绝单项文件编辑。
- 在会话进行中使用后续提示引导智能体。
